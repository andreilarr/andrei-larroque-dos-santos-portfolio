# Andrei Larroque dos Santos — Portfólio

Portfólio estático desenvolvido com Astro, TypeScript e CSS, publicado em `https://andreilarr.github.io/andrei-larroque-dos-santos-portfolio/`. O workflow em `.github/workflows/deploy.yml` publica `dist/` no GitHub Pages a cada push para `main` e permite execução manual.

## Requisitos e comandos
- Node.js 22.23.4 ou superior.
- `npm install` instala dependências e atualiza `package-lock.json` quando apropriado.
- `npm run dev` inicia o preview local.
- `npm run build` gera o site em `dist/`.
- `npm run preview` serve a build estática.

O conteúdo do portfólio permanece baseado em trabalhos e informações que Andrei confirmou para publicação. A branch legada `master` foi preservada; o site é mantido na `main`.
